# 🧪 Amazon.in Manual Testing Project

## 📌 Project Overview

This is a **Manual Testing project** performed on Amazon.in, an e-commerce web application.

The purpose of this project is to practice writing, executing, and documenting test cases for different features of an e-commerce application.

## 🌐 Application Tested

* **Application:** Amazon.in
* **Testing Type:** Manual Testing
* **Browser:** Google Chrome
* **Operating System:** Windows
* **Documentation Tool:** Microsoft Excel

## 🧪 Testing Covered

* Functional Testing
* Positive Testing
* Negative Testing
* Boundary Value Analysis
* UI Testing
* Test Case Execution
* Defect Reporting

## 📊 Test Case Coverage

| Test Type               | Number of Test Cases |
| ----------------------- | -------------------: |
| Functional Testing      |                   30 |
| Negative Testing        |                   10 |
| Boundary Value Analysis |                   10 |
| **Total**               |               **50** |

## 📁 Excel Project

The Excel workbook contains the following sheets:

* **Project_Info** – Project and testing information
* **Functional_Test_Cases** – 30 functional test cases
* **Negative_Test_Cases** – 10 negative test cases
* **Boundary_Test_Cases** – 10 boundary test cases
* **Bug_Report** – Used to document defects found during testing
* **Test_Summary** – Test execution summary
* **Instructions** – Project guidelines

## 📝 Example

**Test Scenario:** Add a product to the cart

**Expected Result:**
The selected product should be added successfully to the shopping cart.

**Actual Result:**
Product was added successfully.

**Status:** PASS

## 🐞 Defect Reporting

If any defect is identified during actual testing, it can be documented with:

* Bug ID
* Bug Title
* Steps to Reproduce
* Expected Result
* Actual Result
* Severity
* Priority
* Status
* Screenshot/Evidence

> Only defects actually reproduced during testing will be reported.
